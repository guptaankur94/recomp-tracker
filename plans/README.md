# Saved plans

`recomposition-split-original.json` is the creator's own Recomposition Split exactly as it was built into the app, personal weights included. It is kept here as a backup and is not shown in the app.

New users see a general version of it under Plan → Starter plans as "Recomposition Split 5×" (Creator's plan). That version has the same exercises, sets, reps and rest, with effort targets instead of personal weights.

To use this file on a phone: Plan tab → Import a file → pick this file. That replaces the active plan; workout history is kept.
